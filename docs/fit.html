02 · remember

Four steps. The model wait is not Worker CPU.

An unchanged page stops after the hash. D1 is updated before the vectors, so the next read does not wait for the index.

01 hash

Same page, stop.

SHA-256 of the Markdown. If D1 already has that hash, nothing is extracted.

02 extract

One JSON call.

Split on blank lines. The model returns entities and edges. Waiting on the call is not CPU time.

03 write

D1, in one pass.

Normalized name is the id. The phone is an alias row. lives_in and quoted_price point the old row at the new one.

04 embed

Vectorize, after.

Name vectors and edge vectors. A fresh upsert can take a little while to show up in query. D1 does not wait.
